## 短时资源采样

PE 审计将明确的系统接口与必须随包携带的依赖分开。新增系统名单项依据 Microsoft 文档：[ComBase / RoRegisterActivationFactories](https://learn.microsoft.com/en-us/windows/win32/api/roapi/nf-roapi-roregisteractivationfactories)、[OpenGL32 / wglCreateContext](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-wglcreatecontext)、[Windows 随附的 DbgHelp](https://learn.microsoft.com/en-us/windows/win32/debug/dbghelp-versions)。没有复制或替换系统 DLL，也没有因为本机恰好存在某个 DLL 就将其放行；最终 13 个 PE 的普通及延迟导入闭包通过。动态 GPU 驱动不在此静态审计范围内。

最后两处修复前，在可见桌面、全新项目隔离数据下启动空白窗口，默认渲染器后台空闲采样 5.036 秒：工作集 203,366,400 字节，私有提交 116,858,880 字节，CPU 时间增加 0.03125 秒。

最终 GUI 在命令沙箱的隔离桌面启动并建立私有数据库后，再采样 5.011 秒：工作集 213,188,608 字节（203.31 MiB），私有提交 120,070,144 字节（114.51 MiB），采样粒度内 CPU 时间增加 0 秒。程序 SHA-256 为 `d11b16d7b60bbd5862646fa58b250a6b6241fe7fe1c6e61ae7506f48b3b04a6a`。该检查不会切换用户前台。

这些样本只包含 UI 进程，不包含下载进程树或独立 GPU 显存，不能据此推出完整负载性能。未把进程 input-idle 时间当成界面可交互启动时间。

## 环境与清理

构建使用项目 `.build/cargo`、`target` 和私有临时目录，单 job、BelowNormal 优先级；测试单线程、分批执行。已有 Rust、MinGW 和 NSIS 只读复用，不安装全局工具、不改变全局 PATH。

GUI 指定全部 FLOW_ROAMING_DATA_DIR、FLOW_LOCAL_DATA_DIR、FLOW_DOWNLOAD_DIR 和 FLOW_DATA_DIR。命令沙箱窗口与可见桌面不共用测试数据，避免权限差异；没有修改系统 ACL。测试程序只读本次运行依赖并写项目测试目录。2026-11-17 的前台验收尝试结束后，核对可执行文件路径，仅关闭本轮启动的 GUI 与样本服务，并删除 `test-artifacts/ui-acceptance` 私有数据；没有终止不明工具进程，也没有执行安装器。

目录整理已将验证后的原生文件合入桌面根，逐文件核对 2,179 项；更新 280 项并按旧清单哈希清除 571 项旧运行文件。原生 canonical 清单与编译输入一致，第三方材料 ZIP 未改动。完整载荷哈希表为 release/liuguang-2.0.0-payload.json。旧前端/Tauri 源码暂留作设计对照、不进入原生源码包；旧 1.0.2 安装包暂留。
