## 构建边界

使用项目内 `.build/cargo` 与 `target`；只在子进程环境设置构建变量。现有 Rust 编译器和 MinGW 只读使用，不安装系统工具链。图形运行验证必须显式指定全部应用数据隔离目录，不能只指定核心目录。
