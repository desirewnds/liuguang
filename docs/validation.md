# 原生验证说明

验证只使用项目内独立数据和合成媒体，不读取个人浏览器登录，不扫描代理端口，不访问用户视频目录，也不使用网页版服务。2026-11-16 用户要求避免高强度测试，因此本轮单 job、低优先级构建，测试单线程分批运行，不执行持续压力或长稳负载。

## 检查入口与证据边界

| 检查 | 命令或入口 | 能证明的范围 |
| --- | --- | --- |
| 纯界面模型 | cargo test -p flow-gui --no-default-features --lib -j 1 -- --test-threads=1 | 选择、范围、导出、大小和快照合并 |
| 应用事件 | cargo test -p flow-app --lib -j 1 -- --test-threads=1 | 消息有界、关键状态与唤醒 |
| 平台边界 | flow-platform 中指定测试过滤器，单线程运行 | 窗口几何、受管目录、安装恢复；不是实际安装 |
| 下载核心 | flow-core 中相关测试，单线程运行 | 参数、状态、代理、目录和日志边界 |
| 参数目录 | python -B scripts/catalog-audit.py | 323 项目录存在性与类型/入口信息 |
| 原生包装 | packaging/test_native_package.py | 清单、外来文件保护和生成脚本 |
| 原生源码 | packaging/test_native_source.py | 白名单与原生资源准备边界 |
| 真实媒体 | tests/run-integration.py | 短合成媒体经真实引擎下载、合并及产物验证 |
| 原生运行包 | scripts/package-native.py --audit | 实际资源、内嵌清单和安装映射 |
| 界面 | 项目隔离目录下的 release 程序 | 实际渲染和所执行的交互 |

命令应加 --locked --offline 复用已准备缓存。测试先按模块选取，只有新变更或失败才重跑相关部分，不为了增加数字反复全量执行。目录中有入口或帮助不等于所有参数在所有网站都测试过。

## 本地媒体验证

使用两秒、320×180 的合成媒体，生成时限制线程。HTTP 仅监听 127.0.0.1 的临时端口，测试后关闭。依次验证 Unicode/空格路径、真实下载、独立音视频合并、严格画质/显式降级、音频提取、字幕选择和嵌入、已有文件保护、预设、原生 JSON stdout、合集及重启恢复。

产物用 FFprobe 或实际字幕文本核对，不能只检查函数返回。测试目录、TEMP 与下载输出都留在项目范围内。测试不是下载速度或长时间转码基准。

## GUI 隔离

显式设置 FLOW_ROAMING_DATA_DIR、FLOW_LOCAL_DATA_DIR、FLOW_DOWNLOAD_DIR，以及 FLOW_DATA_DIR；全部使用相互兼容的绝对项目路径。仅 FLOW_DATA_DIR 不够隔离外壳写入。隔离模式禁用正式托盘、通知、系统对话框和 Explorer，因此这类系统交互仍需要单独环境验收。

检查已确认的浅色/深色配色、默认 1180×820 和最小 620×360、合集父子层次、原始集号、固定操作区、搜索选择、原始参数、全部高级控件、错误反馈及快捷键。中文输入法、字体回退、多显示器和实际缩放分别记录，不能用一张截图代表全部通过。

## 性能

冷启动可操作界面中位数 ≤2 秒、空闲私有提交内存争取 ≤120 MiB、空闲 CPU <1%、普通交互约100 ms以内是设计目标，不是当前实测值。分别记录 UI 进程、完整下载进程树和 GPU 占用，避免只报较小的一部分。

按用户限制只做短时空闲采样与单次交互观察，不运行持续压力。10,000 条数据的纯模型检查与真实 GPU 大列表操作是不同证据；未执行项目必须保留未测状态，不借助预算或单元测试推导完整性能达标。
