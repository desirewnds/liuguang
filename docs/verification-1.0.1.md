# 流光 1.0.1 验证记录

日期：2026-11-15。目标平台：Windows x64；构建使用 x86_64-pc-windows-gnu。本文记录旧 1.0.1 的数据、运行环境和卸载修复。1.0.0 的历史界面、站点及下载结果不自动视为新版重测结果；旧界面文档不包含在当前原生源码仓库中。

**安装、覆盖安装、1.0.0→1.0.1 升级及卸载未在隔离 Windows 中实测；本记录没有安装器或卸载器执行通过的结论。**

## 本次实现

- GUI 新视频默认保存到 Windows 视频文件夹下的“流光”；旧视频留在原处，历史记录保留原路径。
- 核心配置、历史、任务日志及 GUI 引擎副本进入 %APPDATA%/org.flowdown.desktop/managed-v2/；WebView2、窗口状态、CLI 引擎、CLI 缓存及外壳临时文件进入 %LOCALAPPDATA%/org.flowdown.desktop/shell-v2/。FLOW_DATA_DIR 只重定位核心 managed-v2，不构成完整便携模式。
- GUI 和 CLI 使用独立 yt-dlp 副本。flow.cmd 首次从安装资源复制到 shell-v2/cli-engine/；原生 -U 或 --update-to 更新此副本。FFmpeg、Node 和 CLI 插件仍来自安装包。原始引擎 EXE 保留；直接调用它时不经过包装入口的私有环境管理。
- 子进程缓存和临时目录由应用明确提供；CLI 继承原始字节标准流，并使用 Windows Job Object 约束引擎进程。构建阶段引擎版本查询也将 TEMP、TMP、TMPDIR 限制在项目测试目录，不修改系统环境变量。
- 私有 WebView2 Fixed Runtime 替代共享 Evergreen 离线安装器，不安装 Edge 更新服务。完整官方文件、微软许可、SmartScreen 告知及所需目录权限接入安装包；Runtime 的后续安全更新由应用维护者负责。
- 卸载默认清理自有设置、历史、缓存和私有引擎，保留媒体。/KEEPDATA 保留设置、历史和私有引擎，同时清理可丢弃缓存；它优先于 /DELETEAPPDATA。升级跳过数据清理。
- 旧桌面文件仅按允许的清单和未改变的文件指纹清理；未知或已改变文件、旧共享全局缓存及用户明确指定的外部文件保留。安装文件按包清单处理，未知同名文件冲突拒绝覆盖。所有权不明、目录联接或占用问题导致清理失败时停止，不将失败报告为成功。
- 尝试通过 Windows 官方 API 清理本应用 ID 的通知历史，不扫描其他应用通知或自行递归删除系统通知数据库。Windows 自行维护的诊断、事件和使用记录不在“全部可清除”的承诺范围内。

这些条目描述实现规则；真实 Windows 安装过程是否完全满足规则仍需未来隔离环境验收。

实际生成的 NSIS 脚本中，2,463 个锁定资源已逐一核对入包路径和源文件哈希；确认包含私有 WebView2、CLI helper、flow.cmd 和 GNU WebView2Loader.dll，使用最终升级预检逻辑，没有递归删除 AppData 的指令。CLI helper 的 PE 导入仅包含 Windows 系统 DLL，无 WebView2Loader.dll 或延迟导入，因此安装前临时目录中的预检不依赖已安装 GUI。最终安装模板 SHA-256 为 `1cdf57fb76819ac23e8631570d61add7164faa004a66969aca6b6f04ac030677`。

## 未覆盖的验证与限制

- 安装 UI、同版本覆盖、真实升级、卸载、ACL 在目标系统上的生效及系统残留前后对比均未实测。81 项回归和静态 NSIS 编译不能替代它们。
- 本次没有重新运行原生 GUI 或真实网站下载验证。1.0.0 的 B 站、YouTube 和本地媒体结果仅保留为历史证据；高 DPI、完整交互及长期性能验证的旧缺口仍然存在。
- GUI 与 CLI 成功联网更新并回退的完整路径没有新增通过证据；原生更新受网络及上游服务限制。
- 静态目录联接保护不等同于抵抗同账户恶意并发替换路径的安全沙箱；直接运行原始工具、用户指定外部程序及外部输出路径遵循对应工具自身规则。
- GitHub Actions 工作流已补齐 Runtime 暂存、编译前 helper 资源豁免和构建后严格校验，但尚未在线运行。MSVC、macOS 和 Linux 不属于本次本机验证结果。
- 本记录中的旧 1.0.1 产物未签名、未公开发布。当前原生源码仓库由 desirewnds 维护，应用本体采用 Apache-2.0。第三方来源与再分发边界见 [来源核验记录](third-party-source-status.md)；旧 WebView2 私有 Runtime 文档不包含在当前原生源码仓库中。
